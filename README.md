# 💧 Hydra — Water Reminder

Hydra is a lightweight browser extension that helps users build healthier hydration habits through gentle reminders and a daily water intake tracker.

## Features

- Customizable hydration reminder intervals (30, 45, and 60 minutes)
- Automatic background notifications
- Daily water intake tracking
- Visual daily progress indicator
- 250 ml glass tracking
- Persistent storage using Chrome Extension Storage API
- Automatic daily progress reset

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Chrome Extensions API (Manifest V3)
- Chrome Storage API
- Chrome Alarms API
- Chrome Notifications API
